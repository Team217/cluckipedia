# Start here

This section is for someone who has never seen this project, and maybe
never written a program. Read the pages in order:

1. [The big picture](big-picture.md): what the pieces are and how data moves
   between them.
2. [Glossary](glossary.md): the words that come up everywhere (FRC terms
   *and* programming terms).
3. [Install the tools](install-tools.md): set up your computer.
4. [Your first day](first-day.md): run the tests, run both apps, make a
   tiny change and see it work.

After that, [Using the apps](../use/index.md) shows every screen, and
[How it works](../how/index.md) explains the code.
