# Project files

Every top-level folder and important file. Details for code files are in the
[Tablet code tour](../how/tablet-code-tour.md) and
[Companion code tour](../how/companion-code-tour.md).

## Top level

| Path | What it is |
|---|---|
| `lib/` | Tablet app source code (Dart) |
| `test/` | Tablet app tests |
| `assets/` | Images, fonts and default config bundled into the tablet app |
| `android/` | Android project: permissions, build settings, Kotlin Bluetooth code |
| `ios/`, `linux/`, `macos/`, `web/`, `windows/` | Created by Flutter for other platforms. Not used; the app targets Android |
| `tool/lora_stdio_responder.dart` | Runs the tablet's link code on a computer, for the companion's tests |
| `tool/publish_docs.py` | Copies `docs/` into a Cluckipedia clone for publishing |
| `companion/` | The desktop companion app (Python) |
| `docs/` | This documentation (Markdown + images) |
| `pubspec.yaml` | Tablet app name, **version**, packages, assets |
| `pubspec.lock` | Exact package versions last used (generated by `flutter pub get`) |
| `analysis_options.yaml` | Code style rules (`flutter analyze`) |
| `.gitignore` | Files Git ignores (builds, `ScoutingData/`, virtual environments) |
| `README.md` | Short project front page |
| `TODO.md` | An old to-do list |
| `ScoutingData/` | *Not in Git.* The team's archive of raw match files by year; imported by the companion |
| `build/` | *Not in Git.* Build output, including the APK |

## `assets/`

| Path | What |
|---|---|
| `images/RedField.png`, `BlueField.png` | Field pictures for Pre-match and Auton (**replace each season**) |
| `images/FRC-RedBot.png`, `FRC-BlueBot.png` | Robot marker on the field |
| `images/TC217.png` | Team logo (Submit page, app icon source) |
| `config/default_settings.json` | First `settings.json` on a new tablet |
| `config/default_match.json` | Template for a new match file (old) |
| `fonts/` | Fonts (mostly unused) |
| `tablet_pull/`, `transfer/` | Old tools and templates (see [Known issues](../maintain/known-issues.md)) |

## `android/`

| Path | What |
|---|---|
| `app/src/main/AndroidManifest.xml` | Permissions: Bluetooth, internet, USB host; the USB-attached intent |
| `app/src/main/res/xml/usb_device_filter.xml` | USB chips (VID/PID) that open the app when plugged in |
| `app/src/main/kotlin/com/example/chicken_scratch/MainActivity.kt` | Connects Flutter to the Kotlin Bluetooth code |
| `app/src/main/kotlin/com/example/chicken_scratch/BluetoothSync.kt` | Bluetooth Classic hosting, connecting and messaging |
| `app/build.gradle` | App ID `com.example.chicken_scratch`, SDK versions, signing |
| `settings.gradle`, `gradle/wrapper/gradle-wrapper.properties` | Android Gradle Plugin, Kotlin and Gradle versions |

## `companion/`

| Path | What |
|---|---|
| `chicken_companion/` | The app's Python package |
| `tests/` | pytest tests |
| `PROTOCOL.md` | Points to [Link protocol](protocol.md), where the spec lives |
| `protocol_vectors.json` | Exact protocol examples both apps test against |
| `requirements.txt` | Python packages |
| `README.md` | Short guide (these docs have the full version) |
| `.venv/` | *Not in Git.* The virtual environment |
| `pytest.ini` | Test settings |

## `docs/`

| Path | What |
|---|---|
